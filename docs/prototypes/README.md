# Cinematic homepage exploration archive

The user approved the hybrid of B's connected product hero and A's teaching-day
story for implementation on September 8, 2026. The exploration question was how
to make TutorPal feel cinematic while preserving its indigo/navy identity and
recognizable product behavior. The selected answer combines a layered schedule
hero, four alternating story chapters, purposeful scroll motion, and LINE proof.

[Source snapshot](cinematic-homepage-2026-09-08.tar.gz) preserves all three
development variants, their original images, the development route, and the
design notes before promotion. Paths inside the archive are repository-relative.
Its repository baseline is `999b3afb31e1dd06391251cc57f239bea7bd3f1a`.

This archive is a primary source, not a runtime dependency. It was captured
locally before promotion and is maintained alongside the selected implementation;
no separate throwaway branch was created. Restore the snapshot only in a
separate checkout when reviewing the alternatives; it replaces the marketing
route with the old comparison page.
